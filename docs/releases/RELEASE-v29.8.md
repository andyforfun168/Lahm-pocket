# V29.8 多攒下的成长，提前一点长大

[开始游戏](https://andyforfun168.github.io/Lahm-pocket/) · [发布与下载](https://github.com/andyforfun168/Lahm-pocket/releases/tag/v29.8)

## 成长加速，自己来决定

手记新增「成长加速」。初级、中级和高级拉姆，每20点溢出成长值可抵扣1小时健康陪伴，每阶段最多缩短25%。只有超过下一阶段成长目标的部分可用，也可以先留着。

兑换前会显示需要的成长值和抵扣时间，确认后才扣除。其他成长条件保持，抵扣时间不会额外产生成长值，也不会计入真实健康陪伴。

## 改走小路，也会告诉你

旅行途中临时改变目的地时，旅行模块会提示原选地点与实际去向，配上灵感小灯泡。拉姆还会写下突然改变主意的小缘由。

## 手记里的新纸页

成长加速弹窗采用纸纹、胶带、虚线和手写字，配色跟随拉姆体色。

## 继续原来的陪伴

原有存档、奖章、背包和课程进度继续保留；旧档不会自动兑换。加强连续点击、刷新和多窗口下的兑换保护。

不想让拉姆自己出门时，可以在小屋旅行模块关闭「自动出游」，等你来安排下一趟旅行。

## 更新方式

网页版打开原游戏地址即可。已安装离线版的玩家，请联网后进入「离线下载与更新」，下载完成后切换到V29.8。建议更新前导出一份存档备份，无需重新领养。
