# 🌿 V29.7.1｜一周七天的小黑板

1. **今日特价，每天一幅粉笔小画**
精致小屋的小卖部黑板新增七日田园小画：洒水壶、小蘑菇、浆果篮、热茶杯、胡萝卜、面包纸袋和雏菊。每天凌晨 4 点，随今日特价一起换新；一周七天不重样，同一天刷新仍是同一张。

半价吊牌紧跟英文标题，换新时间固定在「今日特价」下方，完善窄屏和大字号排版。七张插画按当天需要加载。

结业课程统一使用蓝色「当小助教」按钮，移除「查看法术」和重复的小助教入口。已学会的法术，可以回小屋的「小本领」查看。

4. **魔法羊皮纸课程明细**
法术课程明细换上羊皮纸与手写字体，黑色正文搭配朱红重点，课时、消耗和重要规则更清楚。

V29.7 的轻松照料、收藏玩法、奖章分类、动画和出游弹窗修复继续保留。已有存档、进行中的活动和自己选择的小屋主题都会保留。

### 如何更新

网页版继续使用原地址。离线版请联网进入「小屋设置 → 离线下载与更新」，下载完成后切换到新版；更新前可先用「备份这份陪伴」留一份存档。
