# 发布工具

`deploy/` 保存正常网页版的发布清单和 ZIP 校验脚本。GitHub Actions 只在手动运行时部署，通过 SHA-256 和离线资源清单核对正常包，并拒绝测试版文件。

游戏入口、离线存档键和旧版本附件不受目录整理影响。

## 新版本发布前

- [ ] 仓库首页的「更新与下载」指向本次发布。在首页补上新版本的图文介绍，使用正式版的实际画面和简短图注；旧版图文与下载继续保留。
- [ ] 新配图存放在 `docs/media/`，文件名标注版本。在线核对图片均能加载，手机上阅读时不会挤成一团。
- [ ] 更新 [历代更新索引](../docs/releases/README.md)，确认首页、发布页与正式游戏显示同一个版本。若安装或提醒方式有变化，同步 [玩家指南](../docs/player-guide.md)。
